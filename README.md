# User Dashboard Project

## 📌 Overview
This is a frontend User Dashboard built with HTML, CSS, and JavaScript. It fetches user data from an API and allows basic CRUD operations with search, sort, and pagination.

---

## 🚀 Features
- Fetch users from API
- Add new user (Create)
- Delete user
- Search by name or email
- Sort A-Z and Z-A
- Pagination system
- Highlight search results

---

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript (Vanilla JS)
- REST API (JSONPlaceholder)

---

## 📡 API Used
https://jsonplaceholder.typicode.com/users

---

## ▶️ How to Run
1. Download project files
2. Open `index.html` in browser
3. No backend required

---

## 🎯 Purpose
This project demonstrates DOM manipulation, API handling, and frontend logic skills.
